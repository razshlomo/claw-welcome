Privacy Policy

This policy describes how Hezi, a private personal assistant used only by its owner, handles data.

Data accessed

  • Google Calendar: event titles, times, locations and attendees of the owner's calendars.
  • Gmail: message metadata (sender, subject, date) and, when needed for a request, message content and attachments.

How data is used

Data is used only to provide features to the account owner: daily briefs, summaries, search and actions the owner requests. Data is not sold, not used for advertising, not used to train AI models, and not shared with third parties except the service providers needed to run the assistant (the integration gateway and the AI model provider that process the owner's requests).

Limited Use

Hezi's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Google data is processed on demand and is not stored in bulk. Short-lived working copies (for example, a summary or a downloaded attachment) are kept only as long as needed for the task.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: open an issue in this repository.
